# OCR GCSE Maths Tutor

Interactive GCSE Maths lessons for UK students aged around 14-16, starting with OCR GCSE Mathematics J560.

This repository is private while the first version is being developed. It is designed to publish as a static GitHub Pages site when Graham approves making the lessons public.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
